# design-sync notes – @vokaboka/ui

## Setup
- The library was extracted from the Vokaboka game (`../vokaboka/vokaboka.html`). `src/art/character.ts` and `src/art/rooms.ts` are 1:1 ports of the game's SVG drawing code (`// @ts-nocheck`). When the game's figures or rooms change, port them again here.
- Build: `npm run build` (esbuild bundle + `tsc` for `.d.ts`). The CSS ships as `dist/index.css` (`cfg.cssEntry`).
- No playwright browser cache on this machine. Render check and capture use the system Chrome: `DS_CHROMIUM_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe"`. Playwright was installed in `.ds-sync/` with `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`.
- Fonts (Baloo 2, Andika) come from a Google Fonts `@import` at the top of the CSS. That produces `[FONT_REMOTE]`, which is expected.
- Groups are assigned through `docsMap` stubs in `.design-sync/groups/*.md` (Actions, Words, Feedback, Layout, World).
- Every preview is wrapped in `VokabokaRoot` with 16px padding via `cfg.provider`.

## Fixes made during the first sync
- The `.vk-root button` reset beat the `.vk-btn`/`.vk-wordcard` backgrounds on specificity, so buttons rendered transparent. The reset is now `.vk-root :where(button)`. Keep resets at zero specificity.
- `.vk-option` used to set `--c` itself and overrode the `vk-c-*` colour classes, so every option was pink. It now only reads `var(--c, …)` with a fallback. Components should never define `--c`/`--cd` themselves.
- `Character crop="head"` needs `overflow:hidden` (`.vk-character--head`); otherwise the whole body shows.
- Bash heredocs containing these preview sources failed to parse in Git Bash on this machine. Writing them through a Python file worked.
- One large `write_files` call (106 files) failed with "socket hang up". Upload in chunks of at most 20 files.

## Re-sync risks
- The art modules are copies, not imports. If the game's `charSVG`/rooms change, this library drifts without warning. Re-run `port_character.py`. The rooms are still the 1.0 port; the game's walkable house is not in the library.
- Fonts depend on fonts.googleapis.com at runtime. Offline designs fall back to Trebuchet/Segoe.
- Logo: the 2nd letter matches no colour rule and renders in ink. That's on purpose and identical to the game.
- The GiftBox "open" state uses the paper background and almost disappears on paper surfaces. Place it on a white card (as QuestionCard does).
